### AI Engineer — LLM, RAG, AI-агенты

Делаю сервисы на языковых моделях и сам веду их в проде: поиск по профессиональным базам знаний с цитатами до пункта, голосовые агенты, агенты поверх рабочих систем (CRM, таск-трекеры), генерацию документов и контента.

Основной стек: Python (FastAPI, async, pytest), PostgreSQL / pgvector, Docker, Linux; Claude, OpenAI, Gemini; Voximplant; n8n.

Как работаю: качество меряю регрессионным эвалом на размеченном наборе, поиск отдельно от генерации. Новое поведение выкатываю под флагом, перед правкой прода делаю снапшот, после деплоя проверяю здоровье сервиса. Каждый воспроизведённый прод-баг заканчивается тестом.

### Проекты

Почти все системы ниже работают у заказчиков, поэтому в репозиториях разборы кейсов: задача, архитектура, ключевые решения и фрагменты кода. Бренды и данные заказчиков обезличены, рабочих сборок и ключей там нет.

**RAG и документы**

- [norms-rag-assistant](https://github.com/Abasov11/norms-rag-assistant) — ассистент инженера по строительным нормам: ответ с цитатой до документа, пункта и страницы, разбор PDF еврокодов, эвал качества.
- [opz-generator](https://github.com/Abasov11/opz-generator) — сборка проектной документации (.docx) из PDF-альбомов; каждая ссылка в тексте сверяется с источником.

**Агенты и голос**

- [voice-sales-agent](https://github.com/Abasov11/voice-sales-agent) — голосовой агент исходящих звонков: квалифицирует лида и передаёт исход в CRM, кампании по расписанию из дашборда.
- [chat-to-tasks-bot](https://github.com/Abasov11/chat-to-tasks-bot) — агент, который превращает поручения из рабочих Telegram-чатов в задачи Bitrix24; изоляция доступа держится на архитектуре, а не на промпте.
- [telegram-agent-bridge](https://github.com/Abasov11/telegram-agent-bridge) — личный ИИ-ассистент в Telegram поверх headless Claude Code: несколько пользователей с изолированной памятью, ротация сессий без потери нити, гарды на ответ.

**Контент и генерация**

- [news-content-pipeline](https://github.com/Abasov11/news-content-pipeline) — конвейер новостного контента: карусели, вертикальные ролики с озвучкой и недельный дайджест на трёх языках, одобрение человеком перед публикацией.
- [brand-post-engine](https://github.com/Abasov11/brand-post-engine) — конвейер брендовых промо-постов с автоматической вёрсткой обложек.
- [floorplan-designer](https://github.com/Abasov11/floorplan-designer) — расстановка мебели по 3D-скану помещения, смета, DXF/PDF.

**Сервисы и инфраструктура**

- [metacritic-ai-watch](https://github.com/Abasov11/metacritic-ai-watch) — сервис-наблюдатель: сбор данных, пересказ отзывов моделью, веб-каталог и мониторинг воркеров; полный код, 371 тест, CI.
- [vpn-infra](https://github.com/Abasov11/vpn-infra) — self-hosted VPN: самовосстановление, атомарные обновления с откатом, учёт трафика.
